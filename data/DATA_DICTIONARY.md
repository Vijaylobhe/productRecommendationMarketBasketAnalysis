# Data dictionary

All data is synthetic, generated by `scripts/generate_data.py` (seed 42) for FreshCart, a fictional three-store grocery chain. It covers 1 January to 31 December 2025.

## `raw/transactions_raw.csv`

Point-of-sale export, one row per line item. 38,652 rows, 8,060 invoice numbers. Data-quality issues are left in on purpose (see below).

| Column | Type | Example | Description |
|---|---|---|---|
| `invoice_no` | text | `INV104217` | Basket / receipt identifier. A `C` prefix (`CINV104217`) marks a cancelled invoice. |
| `invoice_datetime` | text, `YYYY-MM-DD HH:MM` | `2025-03-08 17:42` | Local time the basket was rung up. Stores trade 08:00–22:00. |
| `customer_id` | text, nullable | `C01855` | Loyalty-card ID. Empty for guest checkouts (about 12% of invoices). |
| `store_id` | text | `S01-Downtown` | One of `S01-Downtown`, `S02-Riverside`, `S03-Northgate`. |
| `product_id` | text | `P018` | Foreign key to `products.csv`. Always present and valid. |
| `product_name` | text, nullable | `Spaghetti` | Name as typed at the till. May be missing, upper/lower case, or padded with spaces. |
| `category` | text | `Pantry` | Product category at time of sale. |
| `quantity` | integer | `2` | Units on the line. Negative for returns and cancellations. |
| `unit_price` | decimal, USD | `1.59` | Shelf price per unit. `0.00` marks POS test rows. |

### Known data-quality issues

| Issue | Rows | Handling |
|---|---|---|
| Cancelled invoices (`C` prefix) | 274 | Dropped |
| Returns (quantity ≤ 0, not cancelled) | 120 | Dropped |
| Zero-price test rows | 15 | Dropped |
| Exact duplicate rows (scanner double-reads) | 379 | De-duplicated |
| Non-canonical `product_name` (case, whitespace) | 1,147 | Replaced from product master via `product_id` |
| Missing `product_name` | 191 | Replaced from product master via `product_id` |
| Guest checkouts (no `customer_id`) | 935 invoices | Kept; excluded only from customer-level queries |

## `products.csv`

Product master, 40 rows.

| Column | Type | Description |
|---|---|---|
| `product_id` | text | Primary key, `P001`–`P040`. |
| `product_name` | text | Canonical product name. |
| `category` | text | One of 9 categories: Dairy, Bakery, Produce, Pantry, Beverages, Alcohol, Snacks, Meat & Seafood, Baby & Household. |
| `unit_price` | decimal, USD | Standard shelf price. |

## `processed/transactions_clean.csv`

Output of the notebook's cleaning step: 37,864 line items in 8,000 baskets. It has the same columns as the raw file, plus:

| Column | Type | Description |
|---|---|---|
| `line_total` | decimal, USD | `quantity × unit_price`, rounded to cents. |

The SQLite view `transactions` (in `sql/01_schema_and_cleaning.sql`) applies the same rules and also exposes `invoice_date` (date only).

## `retail.db`

SQLite database built by `scripts/run_sql.py`, holding the `products` and `transactions_raw` tables and the `transactions` view. It is regenerated on every run and is not committed.

## Analysis outputs (`outputs/`)

| File | Grain | Key columns |
|---|---|---|
| `frequent_itemsets.csv` | one itemset | `itemset`, `length`, `support`, `baskets` |
| `association_rules.csv` | one rule A → B | `rank`, `antecedents`, `consequents`, `rule_size`, `support`, `confidence`, `lift`, `leverage`, `conviction`, `baskets` |
| `top_product_pairs.csv` | one product pair | the 15 strongest pairs, in the direction with the higher confidence |
| `sql_results/*.csv` | per query | one file per named query in `sql/` |
