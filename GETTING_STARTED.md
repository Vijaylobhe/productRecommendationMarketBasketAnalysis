# Getting Started

## What is this project?

When you shop for groceries, some items tend to end up in the same basket: pasta with pasta sauce, tortillas with salsa, diapers with baby wipes.
This project looks at a year of shopping receipts from a made-up grocery store called FreshCart and finds those "bought together" patterns.
First it cleans up the messy receipt data, for example by removing cancelled orders, returns and duplicate rows.
Then it uses a well-known method called the Apriori algorithm to find product pairs and groups that show up together more often than chance would explain.
Each pattern gets three scores: how common it is (support), how reliable it is (confidence) and how strong the link is (lift).
The strongest patterns become practical ideas for a store: which products to shelve near each other, which to sell as a bundle, and what to suggest at checkout.
All results are saved as tables and charts, and you can explore them in an interactive dashboard that runs on your own computer.
The receipt data is generated by a script, so the results show how the method works rather than how real shoppers behave.

## Step-by-step guide

### Step 1: Install Python

You need **Python 3.10 or newer**. To check what you have, open a terminal (on Windows, use Command Prompt or PowerShell) and type:

```bash
python3 --version
```

On Windows, type `python --version` instead. If you see an error or an older version, download Python from [python.org/downloads](https://www.python.org/downloads/). On Windows, tick **"Add Python to PATH"** during installation.

### Step 2: Open the project folder in a terminal

```bash
cd path/to/productRecommendationMarketBasketAnalysis
```

Replace `path/to/` with the location of the folder on your computer.

### Step 3: Create a virtual environment

A virtual environment is a private space for this project's libraries, so they don't interfere with anything else on your computer.

```bash
python3 -m venv .venv
```

On Windows, use `python -m venv .venv`.

### Step 4: Turn the virtual environment on

**macOS / Linux:**

```bash
source .venv/bin/activate
```

**Windows:**

```bash
.venv\Scripts\activate
```

When it is on, `(.venv)` appears at the start of the terminal line. Repeat this step every time you open a new terminal.

### Step 5: Install the dependencies

```bash
pip install -r requirements.txt
```

This installs pandas, mlxtend, matplotlib, seaborn, networkx and Jupyter. It can take a few minutes. This is the only step that needs an internet connection; after it, everything runs offline.

### Step 6: Run the project

Run these four commands in order:

```bash
python scripts/generate_data.py
python scripts/run_sql.py
jupyter nbconvert --to notebook --execute --inplace notebooks/market_basket_analysis.ipynb
python scripts/build_dashboard_data.py
```

| Command | What it does |
|---|---|
| `generate_data.py` | Creates the shopping data in `data/`. Optional, because the data is already included. |
| `run_sql.py` | Loads the data into a small SQLite database and runs the SQL queries. Results go to `outputs/sql_results/`. |
| `jupyter nbconvert ...` | Runs the whole analysis notebook. It saves the rules to `outputs/` and the charts to `outputs/figures/`. |
| `build_dashboard_data.py` | Packages the results into `dashboard/data.js`, the file the dashboard reads. |

Run them in this order, because each step uses what the one before it created.

### Step 7: Look at the analysis in your browser

```bash
jupyter notebook notebooks/market_basket_analysis.ipynb
```

Your browser opens the notebook at an address like `http://localhost:8888`. Scroll through it to see every step, table and chart. To run a cell yourself, click it and press **Shift + Enter**. To stop Jupyter, go back to the terminal and press **Ctrl + C**.

To see the charts without Jupyter, open the PNG files in `outputs/figures/`.

### Step 8: Open the interactive dashboard

The dashboard is a web page that runs on your own computer. Nothing is sent over the internet.

1. Make sure the virtual environment is on (Step 4) and you are in the project folder (Step 2).
2. Start the dashboard:

   ```bash
   python scripts/serve_dashboard.py
   ```

3. Your browser opens the dashboard at **http://localhost:8000**. If it doesn't, type that address into your browser yourself.
4. Explore it:
   - **Rule explorer:** a chart and a table of every rule. Use the sliders, size filter and product search to narrow them down. Click a dot or a row to highlight that rule, and use **Download CSV** to save the rules you're looking at.
   - **Recommender:** pick products, or an example basket such as "Taco night", to see what the store should suggest next. **Add to basket** adds a suggestion to the basket.
   - **Association network:** a map of which products are bought together. Hover a product to see its partners, or click it to open it in the recommender.
   - **Shopping patterns:** monthly sales, basket sizes, busy hours and top categories. Hover any bar or square for details.
   - **Dark theme / Light theme** (top right): switch the colours.
5. To stop the dashboard, go back to the terminal and press **Ctrl + C**.

**Shortcut:** you can also just double-click `dashboard/index.html` to open it in your browser, with no command needed.

## Common problems

| Problem | Fix |
|---|---|
| `python3: command not found` | Use `python` instead, or install Python (Step 1). |
| `No module named pandas` (or another library) | The virtual environment is off. Turn it on (Step 4), then run Step 5 again. |
| The notebook fails with an error about `retail.db` | Run `python scripts/run_sql.py` first, then run the notebook again. |
| `jupyter: command not found` | Turn on the virtual environment (Step 4). |
| The browser doesn't open in Step 7 | Copy the `http://localhost:8888/...` address printed in the terminal into your browser. |
| The dashboard says "No dashboard data found" | Run `python scripts/build_dashboard_data.py`, then reload the page. |
| `Address already in use` when starting the dashboard | A dashboard is already running. Use that browser tab, or start another on a different port: `python scripts/serve_dashboard.py --port 8001`. |

For the full methodology, results and limitations, see [README.md](README.md).
